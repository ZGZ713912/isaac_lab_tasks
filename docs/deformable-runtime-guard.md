# Deformable 主动悬挂平地约束与 200 Hz 推理

2026-10-11：本次实车反馈来自 `deformable_v3_transformer.onnx`。部署修改保留
该模型的字节、8 × 32 观测和四动作合同。后续 5 帧 MLP 可使用同一运行时
约束；相同奖励不能代替各自的闭环验证。

平地最低角度采用动作投影。使用编码器对应的四个轮心位置拟合支撑平面，
再与补偿后的重力方向比较。估计坡度 ≤3°、轮心共面误差 ≤6 mm、连续确认
100 ms 后，四腿策略动作固定为 0，物理目标回到基准 minangle，当前为 17°。
目标保留原 2 rad/s 速率限制。退出阈值为 3.5°，防止边界反复切换。
因此车身在坡上被调平后，仍通过腿角识别倾斜支撑面。实际机械角度的稳态
误差需同时检查 `/physical_angle`、`/rl_target_physical_angle` 和关节伺服状态。

新增 `DeformableSuspensionGuard` 组件读取底板 BMI088 的 SI 比力、陀螺仪、
编码器底盘速度和腿角。在车体系估算 `dv_b/dt + ω_b × v_b`，以相同时间
常数滤波比力与加速度后相减，并以陀螺仪传播重力方向。较大加速度下降低
加速度计融合权重。`/chassis/rl/compensated_gravity_b` 替代原观测中的重力
方向，仍占原来的三维。电流反馈保持原始合同；平地区域的电流变化不能
改变被投影为零的四腿动作。IMU 超时、明显失重和异常传感器值解除锁定，
通过既有无效动作回退链处理。

支撑平面推算依赖轮心几何与接地假设。轮胎滑移、悬空、底板 IMU 轴向和
加速度标定偏差会影响估计；任意地形的接触状态无法仅凭这组传感器保证。
新增诊断为 `/chassis/rl/flat_hold`、`estimated_support_grade_deg`、
`support_plane_error_m`、`linear_acceleration_b`。确认平地锁定期间应保持
`flat_hold=true`，目标逐渐到达四个 17°，随后不随油门和电流变化摆动。

历史缓存现在在主动悬挂启停、平地锁定进出、观测异常、动作失效和双下重置
时清空。首个有效观测填满历史，动作反馈归零，观测序号继续递增，拒绝重置
前迟到的动作。启停漏清是代码中已确认的问题；实车交替摆动的全部根因仍
需要时间序列验证。

策略观测以 200 Hz 发布，推理预算为 5 ms。历史按训练的 100 Hz 取样：
Transformer 8 帧覆盖 70 ms，MLP 5 帧覆盖 40 ms；上一动作特征也保留
10 ms 时间关系。时间抖动采用因果取样，缺少目标时刻样本时选取最近的
较早观测。发布调度累计固定周期，跳过错过的时刻，避免调度误差逐次积累。
动作最大年龄为 10 ms。MLP 部署准备脚本同步写入这些参数，并以原生推理
P99 <5 ms 检查当前主机的预算。

实现与验证产物在 `outputs/deformable_runtime_200hz_20261011/`。其中
`rmcs-runtime.patch` 是完整部署改动，`source/` 是待应用源文件；写回前
逐文件核对原始 SHA256，保留当前 RMCS 的其他变更，并保存修改前备份。
修改完成后编译 `rmcs_rl` 与 `rmcs_core`。本次工作不启动车辆。

本地 RMCS 源码与安装配置已更新；两个包的完整构建通过。构建后的 C++
测试实际通过 35 项，MLP 历史、导出和部署准备的 Python 测试通过 34 项。
匹配 ONNX 合同通过，错误历史长度被拒绝。当前主机 10,000 次实际 C++
PolicyModel 推理 P99 为 0.132759 ms、最大 0.207189 ms，均低于 5 ms；
该计时使用合成有限输入，未计入 ROS 通信及车载调度。最终证据为
`outputs/deformable_runtime_200hz_20261011/validation.json`。

配置由构造函数读取，下次启动 RMCS 时生效。实车的 IMU 补偿效果、角度
跟踪精度和交替摆动是否消失，需要现场时间序列验收。
