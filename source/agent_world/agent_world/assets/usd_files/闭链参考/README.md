# 纯底盘

用户确认的两级四杆修复几何，统一资产名为`chassis`。

## 文件

- **`chassis.usdc`**：独立底盘几何资产，15个视觉刚体节点，网格和材质内嵌。默认prim为`/Chassis`，米制、Z向上、X向前，原点位于底盘base-link；参考膝内角68°。
- **`preview.usdc`**：可直接用Isaac Sim打开的演示场景，包含相机、灯光、无碰撞网格和12秒的35–80°往复动画。相对引用同目录`chassis.usdc`。
- `kinematics.json`：杆件名称、源关节frame、孔轴坐标及装配分支，便于后续模型集成。
- `manifest.json`：文件SHA、来源、几何验证及当前资产状态。
- `export.py`：在原工作区从只读源证据重新导出的工具；打开USD文件不依赖此脚本。

**打开方式：Isaac Sim → File → Open → 选择`preview.usdc`，选择`/World/PreviewCamera`并播放时间线查看随动。** 单独装配到其他场景时引用`chassis.usdc`。搬移时保留整个“纯底盘”目录即可，不需要Downloads或原reports目录。

## 范围

这是几何与运动学资产，**没有物理刚体、碰撞、惯量、驱动器或PPO策略**。不能直接作为已经验证的动力学训练资产。

静态模型和动画关键帧由闭环求解器生成；动画中间帧由USD插值，插值闭合误差另行测量并写入manifest，不宣称它是约束求解。演示固定原髋角，只按轮网格最低点升降整机，不是高度IK或地面接触仿真。

颜色：曲柄紫、下连杆金、大腿灰、三孔摇杆绿、上连杆橙、小腿蓝、轮子深灰。颜色仅用于识别几何组件，不表示质量、材料或主动轴已经确认。
