# source/agents — AI Agent 规划文档目录

> 本目录存放**给 AI 编码 Agent（如 Claude / Copilot / 本仓库的 RL 工作助手）在动手前阅读的
> 规划、任务拆解、交接与决策文档**。
>
> ⚠️ **消歧**：本仓库里 `agent_rl` / `agent_tasks` / `agent_world` 中的 "agent" 指
> **RL 智能体（机器人）**；本目录 `agents/` 的 "agent" 指**使用本仓库的 AI 助手**。
> 两者无关，勿混用。放文档时请统一以"AI 规划文档"身份自述。

## 什么文档放这里

适合放这里（跨模块 / 跨任务、面向后续工作的）：

- 阶段规划与任务拆解（如"下一步把 infantry_v4 接成新任务"的实施计划）
- 大改动的设计方案与约束备忘（obs/act 合同、频率、增益等 sim-to-real 红线）
- 踩坑与复现记录（机器环境、渲染器问题、gitignore 坑等，供 Agent 快速上手）
- 交接文档（上次做到哪、下次从哪里继续）

**不适合放这里**：紧贴某段代码的说明文档仍按仓库惯例**就近放在代码旁**，
例如 `wheelbipe/ENV_LAYERS.md`（三层环境继承全解）、`wheelbipe/TASK_TEMPLATE.md`（新任务模板）
保持原位，不要挪进来——Agent 读代码时顺路就能看到。

## 命名与格式约定

- 文件名：`<日期或序号>-<一句话主题>.md`，如 `2026-09-10-port-infantry-v4-task.md`
- 中文书写（与仓库现有文档一致），文件头统一用下面的模板
- 一份文档只讲一件事；要更新就改原文件，不要堆"副本 v2"

## 文档模板

```markdown
# <主题>

- 日期：YYYY-MM-DD
- 状态：planned / in_progress / done / blocked
- 相关代码：`source/...`（路径列表，方便 Agent 定位）

## 背景
（为什么做这件事）

## 目标 / 验收标准
（做完怎样算对，可量化）

## 约束与红线
（obs/act 合同、频率、增益、.gitignore 坑、Arch 环境限制等）

## 方案
（改动点：文件级清单）

## 任务清单
- [ ] 步骤 1
- [ ] 步骤 2

## 历史
（更新记录：谁在何时做了什么）
```

## 给 AI Agent 的使用约定

- 接到任务时**先扫一遍本目录**：有相关规划文档 → 先读它，按其中方案与约束执行；
- 执行中出现与计划不符的发现 → 回写本目录对应文档（更新状态/方案），保持文档与代码同步；
- 完成大块工作 → 新建/更新交接文档，写明当前进度与下一步。
